Answers

Frequently asked questions

Are worldwide coordinates evenly distributed?

Yes. Worldwide mode samples latitude by spherical surface area so points are distributed evenly across the Earth instead of clustering near the poles.

What does Land Only include?

Land Only uses local Natural Earth country geometry to keep generated points on represented land areas, including major islands and Antarctica.

Which coordinate order does GeoJSON use?

GeoJSON always stores coordinates as longitude, latitude. CSV and JSON can use either latitude, longitude or longitude, latitude.

How does the seed work?

The same seed and generation settings produce the same coordinate sequence, which is useful for repeatable tests, datasets and shared examples.

Does the app work offline?

After the first successful visit, the PWA caches all local app files and geographic data. Later visits try the network first and use the cache when the network is unavailable.
